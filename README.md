# LED RENT — изображения для сайта

Изображения для лендинга аренды LED-экрана на Tilda (Ростов-на-Дону).

Важно: представленные сцены являются иллюстративными визуализациями, а не фотографиями выполненных заказов.

Файлы находятся в папке `images/`. Публичные ссылки формата `https://raw.githubusercontent.com/Delinje/led-rent-assets/main/images/hero.jpg`.
